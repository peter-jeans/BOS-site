Get help without handing over your project.

This is the public starting point for Cloud BOS support. Identify the environment and the kind of problem, share only compact status, and keep source code, credentials, raw logs and customer data private.

Codex Claude Code Base44

Start with the smallest safe check

Choose the path that matches what failed. A connection problem is different from project-governance drift or an application problem.

1

Connection

Run the read-only Cloud BOS connection check in your installed host. Record the broad transport result and whether the platform is connected.

2

Project governance

Record whether the project is unbound, governed, stale or drifted. Do not repair, remove or overwrite governance until an exact current plan is approved.

3

Application behavior

Confirm whether the application still opens and its ordinary data path still works. Cloud BOS is build-time guidance and must not become an application runtime dependency.

Prepare a privacy-safe summary

Include only what support needs to route the issue:

  • environment: Codex, Claude Code or Base44;
  • installed Cloud BOS plugin version, when visible;
  • issue category: connection, governance, entitlement, billing or availability;
  • compact states such as transport_status, platform_connection_state and project_governance_state;
  • a privacy-safe receipt or incident reference, if one was created.

Never send

  • passwords, API keys, access tokens or private keys;
  • private source code or full prompts;
  • raw logs, database exports or screenshots with private data;
  • customer, student, employee or tenant records;
  • Master BOS, LDP:FULL, DevPack or private governance internals.

If Cloud BOS is unavailable

Your application should continue to operate. Pause governed writes, keep the last verified project state, and record a compact availability issue. Do not weaken authentication, paste a token into source, or replace an approved governance plan to work around an outage.

Removing a host connection, workspace skill or project-governance projection must be handled separately and must preserve the application, its data and its normal runtime behavior.

Contact and escalation

Use the support handoff supplied with your private-beta access and include the privacy-safe summary above. This website is the canonical support starting point; a public form or email address will be added only after its delivery and privacy controls are verified.

For suspected credential exposure, cross-tenant access or destructive mutation, stop using the affected Cloud BOS connection and escalate it as a critical incident through that handoff.
