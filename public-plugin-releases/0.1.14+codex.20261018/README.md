# Cloud BOS Public Plugin distribution

This distribution contains only the explicit public-package allowlist. It does not contain Master BOS, LDP:FULL, a DevPack, credentials or customer data.

Release state: SEALED_SELF_SERVICE_BETA_NATIVE_ACCEPTANCE_REQUIRED

Prepared self-registration beta, not a stable release or native acceptance certificate. Use My BOS from the publisher's verified BOS site for account sign-in and current terms. Install the supported host plugin and complete its browser OAuth; no personal token is included. Each project needs its own exact baseline, reviewed plan and fresh readback. Local folders currently support one host/platform binding per folder.

Codex marketplace file: .agents/plugins/marketplace.json
Claude marketplace file: .claude-plugin/marketplace.json
Direct plugin folder: plugins/cloudbos-public-plugin/
Publication URLs and current native support must be supplied by the publisher; this package does not create them.
