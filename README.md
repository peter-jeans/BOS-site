# Cloud BOS public website

Marketing-only static website for Build Operating System: benefits, capability
availability, tiers, supported environments and policies.

Published at https://peter-jeans.github.io/BOS-site/ from the main branch.
All customer access, scans and onboarding route to https://bos-client-portal.base44.app/.
The legacy setup.html URL redirects there, including visits using old fragments.
Companion assets remain at their existing paths for compatibility; do not delete or
change their hashes as part of a marketing edit. Historical human setup instructions
are recoverable from commit 05fe728d7f70c3ea22017f4e014b0900050b92d3.

Plugin beta access remains invitation-only. Personalised portal onboarding is being
implemented separately. Policy pages remain labelled drafts; this site does not
enable purchases or issue credentials.
